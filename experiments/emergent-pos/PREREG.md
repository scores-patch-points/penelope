# PREREG — emergent word classes from our own tokens, connected to Dionysius Thrax's eight parts of speech (written 2026-11-20 BEFORE the first run)

Owner's direction (2026-11-20): "we need emergent POS categories connected via Thrax". Reading: the categories are DISCOVERED from the tokens (no tagger, no word list, no tag set in the input); Thrax is the NAMED GIVER they are connected to (his eight classes, as khora's declared translation `THRAX_MAP` in `perceiver/text/wordclass.js`, with ADJ, PART, NUM, PUNCT, SYM, X out of scope as that file declares). A treebank's gold tags are used ONLY to score, never to build or to name a class (the map from an emergent class to a Thrax class is stage 2, below, and is itself a claim).

Split label: **EXPLORATORY** for every number. Data (treebank tokens as given: the segmentation is the treebank's, a stated limitation): Ancient Greek UD PROIEL train (Thrax's own language; khora/identity/pronouns-multilingual/data/grc-proiel), French UD GSD train (same dir, fra), English UD EWT test (the one file read for the sniff, so REUSED for this different purpose; small, about 25k tokens). Sentences are split by index: mod 10 = 0 TEST, = 1 DEV, the rest TRAIN. Seed 20261120. Lower-cased forms.

Method (declared, fixed before the run; not tuned on the test split):
- Types: train types with count >= 5. Context features: the 200 most frequent train words as LEFT neighbour and as RIGHT neighbour (400 dimensions); positive PMI with context smoothing 0.75; L2-normalised. Clustering: spherical k-means, k-means++ seeding, 10 restarts, lowest cost. k is chosen by DEV likelihood from the declared grid {4, 8, 16, 32, 64}: the number of classes is derived, Thrax's eight is NOT the target and is only reported against.
- Held-out model: next-token log-loss on TEST of Witten-Bell word bigram interpolated with a class bigram model, P(w|prev) = (1-L) P_wb(w|prev) + L P(class(w)|class(prev)) P(w|class(w)); L is fit by EM on DEV; types outside the vocabulary form one OOV class.

Claims, each with its falsifier (every language separately):
- **E1 the classes are real (predictive).** The held-out gain in bits per token of the class mixture over the word bigram alone exceeds the MAXIMUM gain over 20 random re-assignments of the same types to classes of the same sizes. Falsified by a gain at or below the null maximum: then the classes are not predictive and nothing below is read.
- **E2 agreement with the giver.** The V-measure between the emergent classes and the Thrax class of each type (the type's majority UPOS in TRAIN gold through THRAX_MAP, in-scope types only) exceeds the MAXIMUM over 200 shuffles of the Thrax labels. Falsified otherwise: the emergent classes do not line up with Thrax's categories.
- **E3 reported, not claimed.** For each of Thrax's classes present, the best-matching emergent class's precision, recall and F1; and which classes do NOT emerge (an honest gap, e.g. the article in English where "the" and "a" may merge with other determiners, or the participle, which Thrax defines by mixing verb and noun and UPOS has no tag for).
- **Stage 2 (not run here; its own protocol first):** the connection by Thrax's OWN criteria checked on the emergent classes alone, from the Techne: the article is placed before or after the noun's inflection (a class that attaches to the noun class); the preposition is placed before all other parts (a class whose right neighbours span all classes); the conjunction binds discourse (a class between two members of the same class); the pronoun substitutes for a noun (shares contexts with the noun class); the adverb is undeclined and goes with the verb (invariant forms, attaches to the verb class); the verb has tense, person and number (stem-sharing variants in the class); the noun has case (variants). Each criterion is a testable behaviour of an emergent class and the verdict is a ledger layer with a calibration card.
