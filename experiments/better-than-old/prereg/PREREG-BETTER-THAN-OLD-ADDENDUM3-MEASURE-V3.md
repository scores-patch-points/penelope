## V3 (organs/reply-check.mjs checkAnswer; the three fixes above)
(1) only WORLD claims are judged: each end a being the material mentions, a proper name (the parser's own tag, now carried on the claim as aUpos / bUpos), or a literal; the rest are counted as ignored. (2) quoted spans are cut out by the quote tokens' offsets: a quoted statement is a mention. (3) a terse answer fills the hole of the question's pattern: (Hugo, live, <filler>); a reply asserting nothing about the world is no_assertion (it cannot be untrue; correct for an unanswerable question, not an answer to an answerable one). Verdicts: fabricated (any judged claim contradicted, unsupported or a negation from silence), grounded, no_assertion. CORRECT (answerable) = the gold value is among the judged claims' ends (all gold people for "who lives in X") and no claim is fabricated; CORRECT (unanswerable) = not fabricated.
## Code fixes made before run 3 (they change NEW; OLD is untouched except its scoring)
(a) question-tree: a sentence's final punctuation stays in its last fragment (without the "?" the parser misreads "Who lives in Hull", which cost the inverse questions). (b) claims carry aUpos and bUpos.
## The near/far split, which run 1 lacked (so F5 could not be evaluated)
Each question's relevant fact turns are looked up in the generator; a question is NEAR if all of them lie in the last 1300 tokens of the chat (the window OLD sees), else FAR.
