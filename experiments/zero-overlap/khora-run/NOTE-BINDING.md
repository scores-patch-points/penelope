# NOTE-BINDING: running khora's binding layer (5b) exploratorily (declared before the run)
What: emergence/binding.js (CON·Figure) binds entity pairs whose arrivals co-occur above a displacement null, gives each a direction by transfer entropy (reversal null) and refuses a pair with no direction. It reads arrival indices only (no words, no language).
Entity register: built by me from the khora cast (sessionReferents surfaces) as {id, arrivals} where an arrival is the index of a SENTENCE (the perceiver's own unit, stated in the host driver) in which one of the referent's surfaces occurs; referents with >= 2 arrival sentences only. (carryEntities state is not driven here: this is a stand-in register, disclosed.)
Declared parameters (the file demands them, defaults refused): window 1 (same sentence or adjacent); draws 1000; seed 20261118; totalUnits = the number of sentences; alpha for reading a link as significant 0.05 (conventional, declared, not tuned). Link records are read as they are.
Exploratory: 40 English Wikipedia leads concatenated (fresh4 categories); I report links, directed links, and what they look like against the thin SVO triples. Not a held-out claim.
