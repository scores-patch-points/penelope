# PREREG-KINDS: what kinds of relationship exist in the wild? (filed before it was run). EXPLORATORY.
User steer: look at all past attempts to parse text into phaseposts; get there by the three questions; but also see what relationships actually exist in the wild: just run kind induction on them. DMD = difference that makes a difference.
Material: the 6,435 relation triples khora's constitutional reader found in 321 English Wikipedia leads (14 article groups; leads-en-div.txt, the same corpus as PREREG-TINBERGEN).
Instrument: khora's own kind inducer (kernel/terrain-induction.js + entity-kind-induction.js: induceEntityKindCandidates), the same call native/the-fold/kinds.js makes. Entity = one relation. Evidence is STRUCTURAL AND GENERAL, never a topic list (kinds.js's own rule): predicate (the connective/verb the reader returned, lowercased), predicate class (copula / locative preposition / other preposition / other), object lead class (determiner / preposition / numeral / capitalised name / lowercase word), object has a digit, object length bucket (1, 2, 3-4, 5+ words), subject class (capitalised name / lowercase noun / pronoun / numeral), polarity. No article category, no named entity, no topic word is fed in.
Nothing is imposed: no Aristotle class, no Tinbergen class, no phasepost cell is used to form the kinds. AFTER the kinds are induced I (a) read each kind's defining parameters and examples, (b) classify every member with phasepost.js + ActPrior@1 and report the cell and the three-question reading (Q1 how structured, Q2 level of reality, Q3 kind of thing) where it is attested, and (c) test whether the kinds line up with the cells beyond chance (permutation of cell labels over members, 1000 draws, seed 20261118).
Declared before running: the inducer's own population label "relations:wiki-div" and its own nulls (cohesion null, p-value, passed); I use its `passed` flag as given, no threshold of mine.
Falsifier (in advance): if fewer than 3 kinds pass the inducer's own null, or if the kinds cannot be told apart by their defining parameters (every kind's top parameters are the same predicate class), then relationship kinds do not emerge from this thin material and the experiment needs verb-rich relations.
Not claimed: that these kinds are Aristotle's or Tinbergen's or the cube's; anything about other languages; held-out.

## ADDENDUM-2 (before the next run). Instance-level result: V-A and V-B on 3,000 random relations gave 0 kinds, 0 basins (parameters 28 and 30): by the pre-written falsifier, relationship kinds do not emerge when each relation INSTANCE is the entity. khora's own use of the inducer is different (operators.js: "kinds induced from relation-term records"): the entity is the thing whose PROFILE is its relations, and instances share too many common features to separate. So two more declared variants, same inducer, same corpus (all 6,435 relations, no sampling needed at this size):
 V-C (kinds of RELATIONSHIP): entity = a predicate (the connective/verb string, lowercased) with >= 8 occurrences; its evidence = one entry per occurrence for each of: subjClass, objLead, objDigit, objLen, subjHead, objHead (the features of the ends it connects). Kinds that emerge are kinds of predicate by what they connect.
 V-D (kinds of BEING, for the contrast): entity = a subject head word with >= 8 occurrences; evidence = one entry per occurrence for predicate and objLead (what relations it enters).
Same falsifier (>= 3 kinds that pass the inducer's own null, separable by their defining parameters). Reported after the run: each kind's parameters, examples, and the phasepost cell mix of its members' occurrences (cell via phasepost.js + ActPrior@1).
