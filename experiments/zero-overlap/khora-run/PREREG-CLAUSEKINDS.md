# PREREG-CLAUSEKINDS: kind induction on clauses with real verbs, then the three questions (filed before it was run). EXPLORATORY, English.
User: yes, the clause corpus. Material: the lexical-analysis-2.0 repo's English clause run (run_2026-03-19_144302/classified.jsonl): 3,590 clauses with Claude's three-question labels (Q1 SEPARATING/CONNECTING/PRODUCING, Q2 EXISTENCE/ORGANIZATION/MEANING, Q3 BACKGROUND/PARTICULAR/PATTERN; GPT-4's labels sit under the key gpt4 and are used only as a cross-check), five registers (quantum physics 1,000; Greek philosophy 1,000; wisdom literature 595; Taoist 500; Stoic 500).
Instrument: khora's kind inducer, as in PREREG-KINDS (kernel/entity-kind-induction.js::induceEntityKindCandidates, its own cohesion null and `passed` flag). Entity = one clause (3,590 entities: 6.4M pairs, under the Map limit). Evidence is STRUCTURAL AND GENERAL, closed-class and shape only, never a topic word, never a label: length bucket (<=5, 6-9, 10-15, 16+ words); first-word class (pronoun / determiner / preposition / conjunction / wh / capitalised name / numeral / other); has negation; has modal; has a copula form; is a question; passive cue (be-form followed within 2 words by a word ending ed or en); subordinator-led (since because although when if while unless though whereas as); has a quantifier (all every each any some many most no); has a digit; comma bucket (0, 1, 2+); capitalised word count after the first (0, 1, 2+).
NOT fed in: the register, the labels, any lexicon, any act prior. Registers and labels are used only AFTER the kinds exist.
After the kinds: (a) each kind's defining parameters, size and register mix; (b) NMI between kind membership (unassigned = its own group) and Claude's Q1, Q2, Q3 and the 27-cell label, each against a permutation null (1,000 label shuffles, seed 20261118; "above chance" = observed above the 95th percentile of the null); (c) NMI of kinds with REGISTER (a topic control: do kinds just recover register?); (d) the same NMIs against GPT-4's labels as a cross-check.
Control (declared): the same inducer on the same features with the clause-to-feature assignment shuffled across clauses (seed 20261118); it should find no kinds. If it finds as many as the real run, the inducer's kinds are not evidence.
Falsifier (in advance): fewer than 3 kinds pass the inducer's own null; or the NMI of kinds with every one of Q1, Q2, Q3 is within the permutation null (not above chance); or the control finds as many kinds as the real run.
Not claimed: that structural features are the right evidence (a negative result is about this evidence); other languages; held-out.

## ERRATUM-1 (after the control ran, before it was used). The declared control was mis-specified: my first run shuffled WHOLE feature rows across clauses, which preserves every clause's feature profile, so the inducer (which sees only profiles) found the same 2 kinds (identical diagnostics). That shows only that kinds are functions of profiles; it is not a null. The intended control destroys the co-occurrence between features: shuffle EACH feature column independently across clauses (marginals kept, joint structure broken), seed 20261118. Run below.

## ERRATUM-2 (user, mid-run): "these are about referents not strings". This experiment's evidence was clause STRING shape (first-word class, comma count, closed-class words). The relationships, phaseposts and kinds we care about are about REFERENTS: resolved things with identity, not word forms. So this run is at the wrong level; its result (2 kinds of 3,590, 4% of clauses, each recovering register more than the three questions: NMI 0.005-0.009 vs register 0.047) says only that clause-string shape tracks genre. The control (independent per-feature shuffle) was stopped before finishing. The referent-level experiment is PREREG-REFERENTKINDS. Same for PREREG-KINDS (predicate strings).
