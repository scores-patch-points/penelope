# RESULT-BINDING: khora's binding layer (5b, emergence/binding.js), run exploratorily on 40 English Wikipedia leads (NOTE-BINDING declared the parameters first)
Run: window 1, draws 1000, seed 20261118, totalUnits = 231 sentences, entity register = my stand-in built from the khora cast (a sentence index is an arrival), referents with >= 2 arrival sentences (99 entities). Code: run-binding.mjs, inspect-links.mjs; output: inspect-en-40.out.
Result: 664 candidate pairs; 205 carry a direction; 79 clear all three nulls (displacement, reversal, reseed) at p < 0.05 and are directed; of the 205 directed links 166 have the two entities co-arriving inside one article and 39 only across articles.
Strongest links read sensibly: Casanare -> Venezuela, California -> Gulf (of California), Mexico -> Gulf, Afghan -> Takhar / Panjshir, Baja California -> Pacific Ocean, Basilan -> Yakans, Oslo -> Middle Ages. They are part-of / adjacent / located-in relationships found without any verb or language. Undirected significant pairs (Philippines / Central Luzon, Manila Bay) are reported by the layer but not emitted as triples.
Reading: the deeper layer gives what the thin SVO layer did not: relationships that are modality-blind (they read arrival indices, never words), statistically tested against shuffles, and directed by predictive asymmetry. Direction is an ASYMMETRY OF ARRIVAL, not a verbal direction ("A before B"), so "California -> Gulf" does not say who contains whom.
Caveats: one corpus of 40 leads; links are corpus-level (not per article); my stand-in register (not carryEntities); 39 directed links are cross-article coincidences (so the layer admits some chance structure: a link needs the within-article check before it is a claim about an article); no French/German run; not compared against any gold relation list; no pair-level equivalence test yet.
