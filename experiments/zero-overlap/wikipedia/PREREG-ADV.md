# PREREG-ADV: the adversary arm (filed before it was scored). DEV ONLY (fr and de act 3); held-out was consumed earlier.
Athena's point: the seeded null models accidents (near-twin articles). An informed adversary has read the ladder and the claimant's text and edits a suitor's text to pass it.
Setup: the existing fr/de pairs, dev split, the same frames (overlap, usage T_all, numerals) with the same induced lexicon and the same per-claimant null thresholds (50 length-matched, seed 20261118). Per claimant, the adversary takes ONE scene-mate (suitor) text (first by sorted title) and appends up to k tokens of the target-language side, never changing the suitor's own text. The adversary knows: the claimant's English text, the frames, the induced lexicon M.
Strategies (budget k appended tokens; k in {0, 3, 10, 30}): S_copy = copy k of the claimant's non-stop tokens (names); S_usage = for k of the claimant's non-stop tokens append one licensed partner each (when a licence exists); S_num = append up to k of the claimant's numerals; S_mix = k split across the three.
Measures: FA_adv per frame and for ladder A = [overlap, usage, numerals] (the adversary as claimant is judged same if it passes some frame and no natural suitor passes that frame; judgeFrames semantics); TP_adv = the true pair's ladder-same rate when the adversary is added as one more rival. k=0 is the control and should reproduce the natural suitor rate.
Falsifier (written in advance): if FA_adv of ladder A at k=10 for any strategy exceeds 0.05 (natural FA is about 0.010), the seeded null does not model an informed adversary, and admission must use the adversary FA, not the null alone. Also reported: smallest k with FA_adv > 0.5 per strategy ("the price of Athena").
Not tested: adversaries that rewrite sentences, an adversary that does not know M, or one that only sees the log.

## ERRATUM-1 (filed after the first run, before any result was used)
The first run of adv.py had a closure bug: the per-claimant `flags` function read the loop variables p and thr after the loop ended, so every suitor and adversary was scored against the LAST claimant. Caught because the k=0 true-pair rate (de 0.204) disagreed with the earlier ladder run (0.688). Fixed by binding p and thr per claimant (default arguments). The first-run numbers are void and are not reported. The protocol, strategies, budgets and falsifier are unchanged.
