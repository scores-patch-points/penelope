# Wikipedia across languages (stamped before any scoring; fetch still running when written)
Question: can the loop call an English Wikipedia article intro and the French (or German) article on the same subject the SAME, using only usage evidence beaten against a seeded null, while rejecting other articles of the same category (suitors)? The articles are independent writing, not translations; gold = Wikipedia's own interlanguage links.
Units: first 120 words of each intro (declared). Pairs kept when both sides have >= 8 words. Categories (suitor groups) as fetched in fetch.py; articles can sit in one category only (first seen).
Split: sha256(en_title + "wp-2026-11-18") mod 20: 0-7 = induce (act 1), 8-11 = induce (act 2), 12-14 = dev choice (act 3), 15-19 = held-out (act 4), run ONCE per language. No tuning on held-out.
Protocol identical to ../bilingual/PREREG.md (sha dd6adb4e754eeb30) + ERRATUM-1: 5-char prefix tokens, 50 stop types per language from the induction set, co-occurrence >= 2 and above the max of 50 seeded within-group shuffles (seed 20261118), rungs T_all / T_mid / T_mid2 (T_rare, T_rare2 dropped: empty by construction), chosen on dev by the admission rule (BA up, suitor-pass not up), 50 length-matched null articles.
Strata (reported separately, labelled before scoring): ZERO = no shared token between the two units after the 50-type stop list; SOME = at least one shared token (names and cognates travel). The claim lives on ZERO.
Baseline: plain shared-token count under the same seeded null (same iff count > max over the same 50 null articles). The loop must beat it on ZERO to count; on SOME it will be near it.
Falsifier: on ZERO, if loop TP is not above baseline TP at suitor-pass within the baseline's, the usage lexicon adds nothing over cognates.
Disclosures up front: category list chosen by me (chemical elements, Nobel physics laureates, Impressionist painters, UN member states, Roman emperors, European mammals, Alpine mountains, rivers of France, cities in Germany, Verdi operas, planets, languages of Europe, cheeses, Paris bridges) and some returned few or no members; fetch hit rate limits on the first pass; intros are not checked by eye beyond a sample of 6.

## ERRATUM-1 (filed after dev, before held-out)
Dev showed the ZERO stratum is empty: French 0 of 196 pairs, German 1 of 189, because intros share names, numerals-as-words, dates and cognates; plain overlap alone gets TP 0.929 (fr) and 0.952 (de) at suitor-pass about 0.03-0.04, and the loop (T_all, chosen) gets TP 0.367 / 0.402 at suitor-pass 0.058 / 0.088. So the stamped falsifier ("on ZERO the loop must beat the baseline") cannot be evaluated: there is nothing in ZERO.
Added stratum LOW, defined from dev before held-out and without looking at held-out outcomes: LOW = true pairs whose shared-token count is at or below the 25th percentile of the dev split's shared-token counts (lowthr.json, per language). The claim moves to LOW. Held-out is run once per language after this. T_all chosen on dev by the admission rule, unchanged.
