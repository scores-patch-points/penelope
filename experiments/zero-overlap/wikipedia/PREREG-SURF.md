# PREREG-SURF: can the asker criterion FIND the equivalent, where mechanical string matching cannot? (filed before it was run). EXPLORATORY: every set was already read.
User (2026-11-19): less interested in forging than in the system being able to surf and find equivalency in a way mechanical string matching can't.
Task: for each English article, rank a pool of candidate other-language leads (the true counterpart plus up to 59 other members of the same category, seed 20261118) and see where the true counterpart lands. Retrieval, not classification: no threshold, no impostor labels.
Rankers: STRING = plain shared-token count between the two leads (first 5 characters of words of 3+ letters, the 50 most frequent tokens of each side removed, random tie-break); STRUCTURE = the asker criterion (organs/asker-dmd.mjs) with the identity askers declared in PREREG-ASKER-F7 (area rel 0.10; birth and death years abs 1; the death asker pulls born in by the dependency order): candidates ranked by the organ's residual among those it can judge (verdict equivalent first, ascending residual), candidates it cannot judge (gap) last; COMBINED = STRUCTURE first, STRING within each tier (and for every gap candidate).
Data: fr and de, fresh sets F1-F7 pooled (already read; EXPLORATORY). Strata by string overlap of the TRUE pair: ZERO (no shared token), LOW (1-3), MORE (>= 4).
Reported per ranker and stratum: P@1, mean reciprocal rank, recall@5; coverage (share of articles whose true counterpart the STRUCTURE ranker can judge); and the counts that matter: articles where STRING puts the truth outside its top 5 but STRUCTURE ranks it first.
Falsifiers (in advance): (1) among articles where the true counterpart is judgeable, STRUCTURE P@1 < 0.80: it does not find the equivalent when it can see it; (2) on ZERO and LOW strata with a judgeable truth, STRUCTURE P@1 does not exceed STRING P@1 by 0.30: no advantage where strings fail; (3) COMBINED P@1 over all articles does not exceed STRING P@1 by 0.05: structure adds nothing beyond strings overall.
Honest limit stated now: STRUCTURE is silent where leads state no area, birth or death year (coverage is low for places); so (3) is expected to be small; the claim being tested is capability where it speaks, not coverage.
Not claimed: held-out or fresh; anything about the informed-impostor result (a separate row); links and containers (not used here).
