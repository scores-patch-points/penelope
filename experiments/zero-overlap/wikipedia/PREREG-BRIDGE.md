# PREREG-BRIDGE: referent bridges learned by USAGE across languages; Wikidata only ratifies (filed before it was run)
Rule from the user's own sessions (relayed by the coreference session): relationships are computed from the reading's own graph; structured data may score or ratify but is never required at run time. PREREG-GROUND-REF used Wikidata Q-ids as the runtime path: its results (if run) are a giver-side CEILING, labelled so. This is the primary path.
Stand-in for the document's own referents (labelled; khora's readWith({referents:true}) is the intended source and is not reachable from this session): the wiki links of each lead (normalised target strings, the article's own self-link removed), per language. They are the authors' own reference structure inside the text.
Bridges (the usage licence, as the earlier token lexicon, but between referents): over INDUCTION pairs, C[(x, y)] = the number of pairs whose English lead links x and whose other-language lead links y. A candidate has C >= 2; it is LICENSED if C exceeds the maximum count seen over 50 seeded shuffles (seed 20261118) in which the other-language link sets are permuted among the pairs of the same category. The 50 most frequent links per language (induction) are STOP. No Q-id and no word list is used to build a bridge.
Frame T_bridge: score(p, q) = the number of distinct English links x of p that have a licensed bridge to some link y of q (x not in STOP). Pass: score above the maximum of 50 length-matched null candidates (other-language leads of other articles in the test set, matched on number of links within max(5, 30%), seed 20261118) and >= 1; default Other. Suitors = the other members of the same category.
Baselines: (a) plain shared-token overlap (5-char prefixes, 50 frequent types removed); (b) NAMES = the number of identical link strings in both leads after folding case and accents (the shared-names baseline that needs no bridge).
Splits: INDUCTION = F1 + F2; DEV = F3 + F4 (one erratum; then FREEZE); HELD-OUT = F5 run once. Disclosure: all of these pairs were read by earlier frames; this frame has not been tuned on them.
Ratification (afterwards; never used to build or choose): the precision of the licensed bridges against Wikidata (a bridge (x, y) is right when the two targets resolve to the same Q-id); the share of bridges whose two ends resolve; reported with the unresolved share.
Reported (fr, de; strata ALL / ZERO / LOW by baseline overlap): TP, suitor pass, BA for T_bridge, tokens, NAMES; number of licensed bridges; ratification precision.
Falsifiers (in advance): (1) on the LOW and ZERO strata (n >= 30), T_bridge must beat BOTH baselines' BA at a suitor pass no higher; (2) ratification precision of licensed bridges < 0.80 means the usage licence is not finding same-referent links; (3) a stratum under 30 is "too small".
Not claimed: that a link is a being in khora's sense; non-Latin scripts; anything the reading's own referents (khora) would add.
