# PREREG-FLUENT: fluent claims (population as of a year) with time and drift (filed before scoring)
Claim: from a lead, the number nearest (within 80 characters, either side) to a population keyword (en population|inhabitants|residents; fr habitants|population; de Einwohner|Bevölkerung). Number parsing: separators (comma, dot, space, NBSP) in groups of 3 = thousands; otherwise a decimal; scale words million(s)/Millionen = 1e6, milliard(s)/Milliarde(n)/billion = 1e9. Excluded: value < 1000; a bare 4-digit integer 1800-2029 with no scale (a year); a number followed by % or /. As-of year = the nearest 4-digit year 1900-2029 within 80 characters of the number, else none. Claim = {subject "X" (the pairing asserts both articles are one subject), predicate population, kind fluent, value, at [year, year] or none, frame "lead-section population of the named entity"}.
Comparison (organs/frame-verdicts.mjs compareClaims, mirrored in Python): agree if relative difference <= tol; else a fluent with no time is BLOCKED (a hole); overlapping times dispute; different times: compatible if the difference <= tol + maxRate x (years apart), else dispute. DECLARED, not tuned: tol = 0.05, maxRate = 0.03 per year. A sensitivity grid (tol 0.02/0.05/0.10 x maxRate 0.01/0.03/0.05) is reported for transparency only.
Arms: true pairs; suitor pairs (the article's claim against each scene-mate's other-language claim). A pair is FALSIFIED only by a dispute. Silence (no claim, or blocked) is a hole, never a vote.
Splits: DEV acts <= 3: read every true-pair dispute by hand, fix extraction bugs in an erratum, FREEZE; HELD-OUT acts >= 4 once. Disclosure: the held-out acts were used by earlier, different frames; this frame learns nothing from them.
Known frame hazard (not controlled): city proper vs metro area, de facto vs official population, and estimates of different dates in the same sentence. Disputes on true pairs are read by hand to separate extraction bugs from genuine source disagreement.
Reported: coverage, true-pair agree / compatible / dispute / blocked, suitor-pair breakdown, by language and split.
Falsifiers (in advance): (1) true-pair dispute rate among comparable (agree + compatible + dispute) > 0.10 on held-out; (2) suitor dispute rate among time-known, both-claim suitor trials < 0.80 (weak power); (3) coverage < 0.03.
Not tested: other fluents (office held, location at a time), a rewriting adversary, Russian.
