# WEAVE-REFERENT: the pieces we already have, woven into one pipeline (2026-11-19)
A map, not a result. Each stage names the piece that does it, where it lives, what is measured, and what is missing. Statuses: BUILT (code and tests exist), MEASURED (a ledger or results file backs a number), DRAFT (authored, not ratified), GAP. Read from the code and docs of khora, janus, pharos, eodb and penelope; I ran none of khora's or janus's organs except where a row is cited. If this and the code disagree, the code wins.

## The thread, in one line
Declare who asks (DEF) -> read the record once through the one door -> make addressed claims -> let embedders and string senses NOMINATE -> check for a witnessed difference that matters -> license sameness only from evidence above a derived null -> return a standing with its stop -> record it as a revisable entry under the referent's birth address -> fold more evidence until nothing changes (REC).

## How the pieces constrain each other (the adherence rules, mechanical)
1. A threshold is derived from the ground's own variation; each quantity owes its own null; a control that admits anything voids the claim (janus identity README, `control_survived`).
2. No ground, no lens, no named adopter: refuse by name, never return false (text-finder, same).
3. Claims are compared only at overlapping grounds; roles, not word order, make the difference ("France is the capital of Paris" is not "Paris is the capital of France").
4. A relation's one-valued / symmetric / acyclic nature is DECLARED by a giver, never assumed from how it is said.
5. A dependency may not point backward in time; an invariant cannot depend on a timed claim.
6. Likeness only nominates; a model may testify (yes/no) under a ground, never decide.
7. Nothing derived is authoritative: deleting caches, marks and indexes changes no answer; retract by weaving.
8. A step may not skip ahead on the cube; structure licenses existence ("correspond supplies, resolve decides").
9. A search that did not run says nothing; absence of a mark proves nothing.

## What is woven and what is still loose
Woven (a path exists end to end in code): read -> claims -> lint veto -> standing -> address -> record, each piece by its owner.
Loose, in the order they matter: (a) the passage-to-claim step on Wikipedia prose (coverage); (b) a derived null for the strength license; (c) the hyperlexicon and the descriptor lane inside the nominator; (d) a ratified ground for referent retrieval; (e) stability under refresh; (f) order-independent merge closure; (g) the model-as-witness question.

## The first end-to-end test this weave implies
One query (document D, referent b, standpoint P declared). Nominate with the embedder (top 10) -> build claims for the nominations and for b's name sentences (gfpClaim, paragraph holons) -> lint for a witnessed difference -> license by janus `same` / FS weight against a null from the ground -> return a standing (not a boolean) with its stop and address -> append as an entry under b's birth id. Scored on a new never-read set against the link gold, with coverage, holes and refusals beside every rate, and the control arm required. Stage 4 of that test is what PREREG-LINT-REDO.md measures now.

## Added after a second search (siblings: scholia, Zenodotus)
- **A derived null, as the house already does it** (stage 5; Zenodotus `derived-priors/concern-priors/README.md`): the null is the text's OWN term population at the same frequency, a floor taken as the max over seeded bootstrap draws from the same power-of-two frequency bin WITHOUT the term itself (leave-one-out), 39 draws so the resolution (1/40 = 0.025) is below alpha 0.05; a second independent seed re-runs the admission and the prior is the INTERSECTION, with the dissent recorded, never silent. A permutation null was tried and REFUSED because it cannot see the text's own grammatical regularity. This is the recipe my failed strength license lacked (row 31 A3 took its threshold from a prior and had no same-frequency-bin null); it also answers the leave-pair-out requirement. Use it for the Fellegi-Sunter weight's `u` side.
- **Concerns can be derived, not only declared** (stage 0): `ConcernField@1` types what a voice dwells on (spread and intense dwellings, entities, byte-addressed spans) mechanically from its full source text, by that same null; it "discloses whose stake the claim is" and never gates or grades. An asker's concern set for `declareAsker` can therefore come from a declared source of theirs, bylined, instead of being typed by hand.
- **Acts** (stage 2): `act-priors/act-prior-en.json` (`ActPrior@1`) maps VerbNet verb forms to the nine acts; `phasepost.js` consumes it to type relations into the 27 cells. A RECEIVED lexicon, ambiguity kept, grain absent. Row 29 measured it thin (4 of 27 cells on thin triples) because the relations the reader supplies are thin.
- **Inspection** (stage 1-2, and for the labelling question): `scholia` renders one read as a static page: words tinted by class, names, pronoun bindings (confident or contested), each sentence as a dependency tree and as a clause nest (relation, marker, subject, predicate, object, polarity). Whoever checks an oracle sample can see what the reader marked beside the text instead of reading JSON.
- **Models as witnesses** (stage 6): janus `pair-witness.mjs` returns RAW yes/no answers from a model (three wordings each way) and never folds them into "same"; what the answers mean under a bound is the asker's to declare. This is the sanctioned shape if a model testifies at all; it is not used in the retrieval pipeline and rule 2 (no model judges sameness) stands.
