# codecs: draft invariance declarations (2026-11-19)
`codec-invariances.draft.json` (`CodecInvariance@1`, status: draft, authored, not ratified) declares, for text, image and audio: how a region is addressed (byte span, box over decoded pixels, time range over decoded samples), what the codec decodes it into, what it treats as accidental, what it followed, what it drops, how each bound is to be MEASURED (a recipe and a state, never a typed number), the evidence the material supplies, how it is forged and what that caps the verdict at, and a falsifier. Shape follows janus `Ground@1` (its `dependency` event is the text invariance). Source of the idea: khora `native/docs/THE-ISTHMUS.md`; theory in `../THEORY-IDENTITY.md` sections 11-12.
Nothing here is built or measured. Every image and audio bound is `bound_unmeasured`, so equality is exact-hash only until a bound is measured against a seeded null. `adoptedBy` is null until a named reader adopts a codec. The eight decisions the owner must make are in the file under `ratification`.
