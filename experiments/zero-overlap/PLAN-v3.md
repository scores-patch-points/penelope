## How I work from here (changes to me, not just the plan)
1. Status lines carry a label. The root-as-common-ground frame is [I]/[G]: its ground test never ran. It is the hypothesis under test, never a headline.
2. No frame is admitted without an ADVERSARY ARM: an impostor that has read the ladder. The seeded null stays (it models accidents); the adversary models Athena.
3. Probes are commit-then-reveal. A hash of the probe is logged before the claimant answers; the probe itself is revealed only at the test. (organs/frame-verdicts.mjs: commitProbe / revealProbe.)
4. Withholding recognition is an act: logged with its reason and an expiry, distinct from a gap (could not see).
5. Authorship is checked before cells are read "by kind, not author": who may write to which cell, and the proof. Reading by cell is kept; writing is gated.
6. The loop's stopper is named outside the loop. Convergence is not claimed; who ends the loop, and on what authority, is declared and bylined.
7. Docs go stale when results change: any result file that changes a claim also lists the documents that now disagree with it.
8. Long fetches save progress as they go and I report partial usable state, not "waiting". Rate-limited sources get a stated pace and a stopping rule up front.

## Definition adopted (user, 2026-11-18)

So: frames become falsifiers; a DMD declares which differences count; "same" = survived N meaningful attempts, with the trail. ## Dependency order and validity (user, 2026-11-18): "holographically aware of the dependency order of things and when and in what frame things are true. The president has one birthplace. The president can be in different places at different times."
Every claim carries (frame, kind, interval, dependsOn). kind invariant = one value for the subject (birthplace); fluent = a value valid over an interval (location, office). Same value agrees; two values for an invariant dispute; two for a fluent dispute only if the intervals overlap, else are compatible; different frames are incomparable; a missing dependency is blocked (a hole, never a guess). Done in organs/frame-verdicts.mjs compareClaims (tests). "Holographic" = every mark carries its own dependency pointers, so any fold can rebuild the order and the validity without the rest of the log. The invariants are also the natural DMD: a difference in an invariant is always a difference that makes a difference; a difference in a fluent only when the times align. Next: extract (subject, predicate, value, interval) claims from the Wikipedia pairs and test agree/dispute against gold (step E), with frame and time as part of the comparison.

## Holarchy: the dependency order made exact (2026-11-18, from the pasted Wilber tenets)
The user pasted a summary of Ken Wilber's twenty tenets (holons: wholes that are parts of wholes; holarchy; each level transcends and includes the one below; depth and span; destroy a holon and everything above it falls, nothing below it). Read as the frame for the fold. Built in organs/relation-fold.mjs (30 tests with frame-verdicts): holarchy (partOf / dependsOn relations), levelOf, destroy (the set that falls with a holon: all wholes above, none below), extrinsic value = size of what falls, profile (depth and span per level, flags violations of "greater depth, less span" as possibly heaps), fingerprint (a name-free canonical form of the dependency order), sameHolarchy (pattern = equal fingerprints; aligned = destroying the same anchored holon takes the same wholes with it). Mapping: GROUND = the shared frame/anchors (equal ground value); FIGURE = the holon itself (its intrinsic depth, its facts); PATTERN = the holarchy (the order of dependence). Odysseus case: marriage depends on bed depends on tree: destroy the bed and the marriage falls, the tree stays; same order in other words = same pattern and ground; same order over different holons (feast/wine on the tree) = same pattern, other ground. Not yet run on real text: needs part_of / depends_on relations from a reader (khora's thin SVO layer rarely yields them) and administrative hierarchies (province part_of region part_of country) from interlanguage-linked articles.
