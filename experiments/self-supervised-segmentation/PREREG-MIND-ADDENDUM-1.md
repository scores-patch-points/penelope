## The classification (it changes what each hypothesis means)
SIG (Existence domain; pharos lib/sig.mjs; the pharos proposal puts its marks in a separate store): DERIVED state that changes COST and never an ANSWER. The law: deleting every derived state, memo and trail changes no answer (PHAROS_NO_SIG=1); a shortcut is used only after it matched the reference on held-out probes and was cheaper; one mismatch demotes it. The ants' TRAILS are SIG: they order the search for programs, so learning and reading get cheaper, and no result may change with them.
A program that CHANGES the reading (a cut applied to the tokenizer's output) is NOT a SIG shortcut: it changes the answer. It is a candidate until Penelope's DEF with a named giver and EVA verdict put it in force. So `mind.mjs` as written applies every program with a positive trail directly. That is read as the CEILING of what adopting the colony's candidates could deliver (as if every candidate were defined and survived), NOT as what the SIG layer delivers. The surprise numbers are reported under that name.
