# ERRATUM-MIND-2 to PREREG-MIND.md, written 2026-11-20 after run `b` (mind-b.out, mind-result-b.json); run `c` was stopped unread
Run `b` (patience derived, ERRATUM-MIND-1) ran to completion and exposed two defects of mine. Its H1/H2/H6 numbers are NOT used for those hypotheses. What it did show, kept as a finding about the criterion, not about the hypotheses:
- 589 programs entered the mind and applying them RAISED surprise on every probe (unseen source +2.93, held-out same source +1.74, edited +3.80; positive = more surprising = lower tagger confidence), while the 10 random minds of the same size raised it more (+3.59 to +6.46, +2.28 to +4.73, +5.76 to +11.15). Beating a random-cut null is therefore NOT a sufficient test of a program; the programs together were worse than leaving the text glued. (The codec session's caution, confirmed.)
- DEFECT 1: a program was `ok` when its change beat the null's maximum; the null's values are negative (a random cut breaks a word), so a program with a NEGATIVE change (worse than glued) could be `ok`. The protocol text said "ok = no null draw reaches the observed change; veto if negative" and the code let both be true. Corrected: a program is `ok` only if its change is positive AND beyond the null: a difference that makes a positive difference.
- DEFECT 2: the stop rule M = max(programs held + 1, 22) grows with the mind, so every batch became exhaustive (about 1000 evaluations of 1000 candidates) and the colony re-evaluated programs it already held. The cost comparison with empty trails (22 against 1180) is meaningless. Corrected: known programs are not re-evaluated (a held program keeps its strength by evaporation alone within the run; the trail is the return deposit already made), and a batch stops after P = 22 consecutive evaluations of NEW candidates that find nothing, the P derived in ERRATUM-MIND-1.
- Also kept: H3a (a reader given only the mind rebuilt from the trails reproduced the probe surprise EXACTLY on all three probes) held in run b; H3b (the mind under 1% of the ingested bytes) did not (6.09%) but is confounded by the 589 harmful programs.
Changes to the harness before run `b2` (the protocol order) and `c2` (reversed order, seed 20261121): `ok` needs a positive change; known programs are skipped; the deposit carries the measured change (`delta`); H6 compares the programs a cold-start colony finds on the last batch with the programs the warm colony holds plus finds there, and the evaluations each spent.
